# Developer Productivity Dashboard

A modern and responsive React-based dashboard designed to help developers manage projects, tasks, productivity, team activity, analytics, and workspace settings.

## 🚀 Live Demo

https://developer-productivity-dashboard-black.vercel.app/

## 📌 Features

- 📊 Developer productivity dashboard
- 📁 Project management
- ✅ Task management with completion tracking
- 📈 Productivity analytics
- 👥 Team overview
- 🔔 Notification panel
- 👤 Editable user profile
- ⚙️ Workspace settings
- 🌙 Dark mode
- 💾 LocalStorage data persistence
- 📱 Responsive user interface
- 🚪 Logout confirmation
- ⚡ Interactive project details and menus

## 🛠️ Technologies Used

- React.js
- Vite
- JavaScript
- HTML5
- CSS3
- Lucide React
- LocalStorage
